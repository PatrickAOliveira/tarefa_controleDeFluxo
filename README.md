# Exercício EBAC Módulo 10

Neste exercício deverá fazer um projeto em Java que faça o seguinte:

- Leitura de 4 notas;
- Calcule a média das notas;
- Exiba a mensagem de aprovado se a média >= 7;
- Exiba a mensagem de recuperação se a média >= 5;
- Exiba a mensagem de reprovado se a média < 5;

## Tecnologias

- Java 11+
- Git
- Visual Studio Code (VSCode)
